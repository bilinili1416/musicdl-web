# Musicdl Web

基于 [CharlesPikachu/musicdl](https://github.com/CharlesPikachu/musicdl) 的中文网页工作台，支持多平台搜索、下载、音乐库及逐句双语歌词。后台采用轻量 Python HTTP 服务，前端采用原生 HTML / CSS / JavaScript，无需 Node.js 或前端构建。

## 启动

需要 Python 3.10+，推荐 Python 3.12。克隆仓库后，在项目目录创建环境并安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

浏览器访问 http://127.0.0.1:8000 。也可以运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，脚本会在缺少虚拟环境或运行依赖时自动安装。更换端口：

```powershell
.\.venv\Scripts\python.exe server.py --port 8080
```

按 Ctrl+C 关闭服务。macOS / Linux 可使用 `python3 -m venv .venv`，随后运行 `.venv/bin/pip install -r requirements.txt` 和 `.venv/bin/python server.py`。

## 功能

- 网易云、QQ、酷我、酷狗、咪咕、千千音乐，多平台并行搜索。
- 默认快速搜索，先展示歌曲信息，下载时再解析音质与链接；可切换完整搜索。
- 按平台筛选、按歌名排序；完整搜索还支持音质筛选与文件大小排序。
- 单首及批量下载，显示排队、解析中、下载中、完成、失败状态。
- 收藏与搜索偏好保存在浏览器 localStorage。
- 自动保存每首歌的播放进度，刷新或重新打开网页后恢复上次歌曲，点击播放即可继续。
- 最近 20 条搜索历史，可点击重新搜索、删除单条或清空。
- 下载历史保存在 `.musicdl-web/history.json`，重启后仍可查看。
- 下载管理支持勾选或全选当前分类，批量删除已完成／失败的下载历史，保留本地音频和歌词。
- 本地音乐支持批量永久删除：弹窗列出歌曲，最终确认后删除音频、关联歌词及所有列表中的对应条目。
- 下载文件保存在 `musicdl_outputs/平台名称/`，可在网页试听或保存到浏览器。
- 音频采用 HTTP Range 支持拖动进度；浏览器支持的格式因平台而异。
- 播放列表：默认全部本地音乐，可自建、重命名、加入／移出歌曲；顺序、随机、列表循环与上一首／下一首。
- 多文件导入到自选列表，保留内嵌歌词；缺少歌词时自动查询，失败时提醒并提供手动补全入口。
- 播放时逐句高亮、自动滚动原文与译文，点击歌词可跳转，支持每首歌曲单独调整歌词偏移。
- 日语歌词汉字上方显示振假名，支持开关，读音在本地生成。
- 整页静态歌词鉴赏，可选中原文和译文、复制纯文本、隐藏译文练习阅读，并提供振假名、字号与沉浸模式。
- 点击歌名查询萌娘百科，解析日文别名；有歧义时提供候选词条与站内搜索入口。
- 支持移动端、键盘导航和 `/` 快捷聚焦搜索。

音质由 musicdl 平台接口实际返回，不进行转码。在搜索框下方选择模式，偏好保存在当前浏览器。快速搜索只查询一页歌曲信息，不查询音频链接、音质或歌词，单个平台最多等待 25 秒；结果标记「待解析」，下载时按原歌曲标识调用 musicdl 解析，最多等待 65 秒，解析失败会显示原因。快速结果不保证歌曲可下载，无法使用音质筛选或大小排序。完整搜索保留原有提前解析流程，单个平台最多等待 65 秒。六个平台都支持快速模式，接口异常时可切换完整搜索或其他平台。

当前搜索结果在服务内保存两小时，服务重启后需要重新搜索；收藏页提供重新搜索按钮获取最新链接。这是结果 ID 的有效期，不会加速重复关键词搜索。服务重启会将未完成任务标为失败，已下载文件保留。快速搜索适配固定的 musicdl 2.14.1，升级上游后应验证平台数据格式和解析方法。

本地服务和平台子进程使用 UTF-8 输出，网页下载关闭上游终端进度条，支持 `M♭` 等含特殊符号的歌名。`musiccompat.py` 在运行时适配固定版本：QQ 第三方解析器使用其自带的请求超时，避免重复传入 `timeout`；链接测试、官方接口超时与平台进程总时限继续生效。解析器异常类型及 HTTP 状态会记录到 musicdl 日志，日志不输出请求地址或凭据。修复本地适配问题不保证平台始终提供下载链接。

## 文件与接口

`web/` 是网页，`server.py` 封装 musicdl。服务默认只监听 `127.0.0.1`。完整云端部署步骤见 [DEPLOY.md](DEPLOY.md)，已提供 Railway / Docker 配置、密码认证、HTTPS 域名检查和持久存储支持。

| 接口 | 用途 |
| --- | --- |
| `GET /api/status` | 引擎版本、平台列表、下载目录 |
| `POST /api/search` | `{keyword, sources, limit, mode: "fast"或"full"}`，返回搜索任务 ID；省略 mode 保持原有完整搜索 |
| `GET /api/search/{id}` | 搜索进度、结果、平台错误 |
| `POST /api/downloads` | `{ids: [搜索结果ID]}`，加入队列 |
| `GET /api/downloads` | 下载队列与历史 |
| `POST /api/downloads/delete` | `{ids: [下载任务ID]}`，仅删除已结束的历史，保留音乐文件 |
| `GET /api/library` | 本地音频文件列表 |
| `POST /api/library/delete` | `{ids: [文件ID], confirmed: true}`，最终确认后删除本地音频及关联记录；返回成功、已不存在及失败项 |
| `GET /api/playlists` | 全部音乐与自建列表，忽略已移走文件 |
| `POST /api/playlists` | `{action: create/rename/delete/add/remove, id, name, files}` 管理列表 |
| `POST /api/imports` | 音频二进制请求体；`X-Filename` 为 URI 编码文件名，`X-Playlist-Id` 为目标列表 |
| `GET /api/imports` | 导入记录、歌词检查结果与失败原因 |
| `GET /api/files/{id}` | 试听；加 `?download=1` 保存文件 |
| `GET /api/lyrics/{id}` | 已下载文件的本地／内嵌歌词与译文时间轴 |
| `GET /api/lyrics/{id}/furigana` | 原文附加本地生成的振假名，不改动歌词或译文 |
| `POST /api/lyrics/{id}/lookup` | 自动匹配或按 `{keyword}` 查找版本；`{songId}` 选择网易云歌词版本 |
| `POST /api/lyrics/{id}/import` | `{kind: "original" 或 "translation", text}`，保存导入歌词 |
| `POST /api/moegirl` | `{title, artist}`，查询歌曲词条、别名重定向与候选项 |

## 播放进度与搜索历史

播放过程中约每 5 秒保存一次位置，暂停、跳转、切歌或离开页面时也会保存。刷新后自动加载上次歌曲与位置，保持暂停以遵守浏览器自动播放限制。不同歌曲分别保存位置，最多保留最近 200 首；播放结束后该歌曲从头开始。文件已移走时会提示并清除失效记录，位置超过文件实际时长时从头开始。主动关闭播放器后，刷新不会自动展开，但重新选择该歌曲仍可恢复进度。

搜索请求被服务接受后加入历史，重复关键词移到最前，点击历史使用当前选中的平台重新搜索。进度、历史、收藏和读音开关均保存在当前浏览器，不会自动跨设备同步；清除站点数据或更换访问端口会影响这些记录。

## 播放列表与本地导入

在「下载管理」选择历史后点击「删除选中历史」，只移除记录；歌名、歌手等信息保存在 `.musicdl-web/library-metadata.json`，音乐库与播放列表仍可正常使用。进行中的任务不能删除。

在「本地音乐」勾选歌曲或全选当前列表，点击「删除选中音乐」。弹窗显示选中歌曲和删除范围，点击「确认永久删除」后才执行；取消不会删除文件。成功后同时清理本地音频、同名歌词、歌词缓存、下载／导入记录、全部播放列表与当前浏览器中的播放进度。不同音频格式共享的同名歌词保留到最后一个格式删除。文件被占用或没有权限时保留该歌曲及其记录，并提示失败原因；其他成功项正常移除。删除列表成员或列表本身仍保留音频。

在「本地音乐」选择「全部本地音乐」或新建列表，点击歌曲旁的 ＋ 加入列表，自建列表中的 − 只移除成员，删除列表也会保留音频。自建列表按加入顺序播放，默认列表按文件修改时间从新到旧排列。顺序播放在末尾停止，列表循环会回到首曲，随机播放每轮遍历歌曲并尽量避免连续重复；随机模式的上一首会沿实际播放历史返回。自动切歌及上一首／下一首从头开始，主动点击歌曲保留该曲的恢复进度。刷新后恢复歌曲、队列和模式，等待用户点击播放。浏览其他列表不会改变正在播放的队列。

点击「导入音乐」，选择目标列表和本地音频，可一次导入最多 50 首，每首不超过 256 MB。原文件会复制到 `musicdl_outputs/LocalImport/`，服务检查音频有效性、读取标题与歌手标签，没有标签时使用原文件名。导入记录和列表保存在 `.musicdl-web/imports.json` 与 `playlists.json`；迁移网站时连同音频目录与状态目录复制。

导入时优先保留音频内嵌歌词。原文缺失时后台查询网易云，严格匹配标题、已知歌手和时长（允许 4 秒差异），只接受唯一版本；缺少歌手标签时必须有时长证据。自动获取平台现有的原文与译文，不生成翻译。原文已存在时继续使用现有的译文补全功能。音频不上传到歌词平台，只发送歌名和歌手。自动补全失败会弹出提醒，并保留在「导入记录」中，可点「手动找歌词」选择版本，或在播放器导入 LRC。网络、版本歧义、未收录和纯音乐都可能导致补全失败，音频仍可播放。未选择的同名旁文件 LRC 不会随音频自动上传；可在播放器另行导入。

## 逐句歌词

打开本地音乐，点击播放，歌词面板会自动展开。优先读取同名 `.lrc` 或音频内嵌歌词，以及同名 `.translation.lrc`、`.zh.lrc`、`.trans.lrc` 译文。双语 LRC 在相同时间戳下的第二行也会显示为译文。

译文缺失时，播放器会将歌名和歌手发送给网易云查找同一版本，只在歌名和歌手匹配时自动保存。获取后保存在 `.musicdl-web/lyrics/`，再次播放不需要联网。音频不会上传。没有自动匹配时点击「在线找歌词」选择同一版本，或用「导入原文／导入译文」选择不超过 256 KB 的 LRC／TXT 文件。导入和在线歌词只保存独立缓存，不覆盖已有音频及原始 LRC。

原文与译文按时间戳对齐，允许 0.25 秒的舍入误差；没有时间轴的歌词以静态文本展示，不假造同步。未匹配的译文会提示。播放器底部可以调整 ±30 秒的偏移，正值让歌词提前，偏移保存在该浏览器。翻译来自平台或导入文件，不自动生成机器翻译；并非所有歌曲都有译文。纯音乐或平台不可用时仍可正常播放。

勾选「日语振假名」后，检测到假名的原文自动生成读音，原文、译文和时间戳保持不变。完全没有假名的日语原文可以关闭再开启开关，手动生成。采用 fugashi 与 UniDic Lite 在本地分词，不需要外部翻译服务；首次安装词典会增加约 250 MB 的环境体积。人名、专有名词、歌词特殊读法及少见字可能不准或没有注音，以原文和官方歌词为准。单行超过 4096 字或整份歌词超过注音预算的部分保留原文。

点击搜索结果、音乐库或播放器的歌名，在 `https://moegirl.icu/` 查询歌曲词条。例如「青のすみか」解析到「苍蓝所栖」。只有能确认是歌曲的精确词条或别名才直接跳转；多义、模糊匹配时显示候选，不自动选择。网络不可用或查无结果时，可改歌名重试或打开站内搜索。歌词行继续用于跳转播放时间。查询只发送歌名，不上传音频或歌词。

## 歌词鉴赏

在本地音乐或已完成下载中点击书本图标，可以直接打开静态鉴赏页，等待用户点击播放；已在播放的同一首歌曲则继续播放。也可从播放歌词面板的「歌词鉴赏」按钮或左侧导航进入。原文与译文按句排列，阅读区不随音乐滚动或高亮，拖动选中也不会跳转播放时间。底部播放器仍可控制播放。

支持隐藏译文、切换振假名、调整字号及「沉浸阅读」。显示偏好保存在当前浏览器。按钮可复制原文、译文或双语全文；选中歌词后也可复制，在歌词区域按 Ctrl / ⌘ + A 可全选。复制内容保留原文汉字与假名、去除注音及时间戳；浏览器不允许自动复制时，会提供可选中的文本框。没有时间轴的译文单独展示，避免错误逐句对照。

配合fushi的浏览器插件使用更佳。
